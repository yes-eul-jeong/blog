# 1. 싱글스레드와 멀티 스레드

<br/>
<br/>

## 1\. 스레드란?
<br/>

우리가 사용하는 프로그램은 대게 한번에 여러 작업을 처리해야한다. 이때 ‘작업의 흐름'을 나누어 실행할 수 있도록 도와주는것이 스레드(thread)이다.

쉽게 말해, ‘작업을 실행하는 흐름’이 스레드다.
<br/>
<br/>
<br/>


## 2\. 싱글 스레딩과 멀티스레딩
<br/>

### 1\. 싱글 스레딩
- 프로그램 전체가 **하나의 스레드** 만으로 실행됨
- 모든 작업이 순차적으로 처리됨. (한 작업이 끝나야 다음 작업 시작 가능)
<br/>

### 2\. 멀티 스레딩

- 여러개의 스레드가 동시에 작동하며 여러 작업을 병렬로 처리
- CPU코어가 많을 수록 더 효과적
<br/>
<br/>
<br/>

## 3\. 장단점 비교

<br/>
  

| 항목  | 싱글 스레딩 | 멀티 스레딩 |
| --- | --- | --- |
| 구조  | 단순함 | 복잡함 (동기화 필요) |
| 성능  | 단일 작업엔 효율적 | 여러 작업을 병렬로 처리 가능 |
| 리소스 사용 | 낮음  | 높음 (스레드 간 자원 공유 고려) |
| 문제 발생 가능성 | 낮음  | 높음 (데이터 경합, 데드락 등) |

<br/>
<br/>
  
<br/>

## 4\. 자바스크립트는 싱글 스레드인데도 빠른 이유

자바스크립트는 기본적으로 싱글스레드 언어지만 비동기처리 + 이벤트 루프 구조 덕에 여러 작업을 동시 처리하는것처럼 보임,

<br/>
  

```
console.log("A");
setTimeout(() => console.log("B"), 1000);
console.log("C");
// 출력: A → C → B
```

<br/>
<br/>

## 요약

- 스레드 - 실행 흐름의 단위
- 싱글스레드는 단순하고 안전, 멀티 스레딩은 빠르고 유연
- 자바스크립트는 싱글스레드지만 비동기 + 이벤트 루프 덕에 효율적인 구조를 가짐
