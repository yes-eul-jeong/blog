## 1\. 이벤트 드리븐이란?
<br/>

> 클릭하고, 터치하고, 드래그하고, 엔터치고. 이 모든게 이벤트 
<br/>


우리가 평소에 사용하는 모든 웹, 앱은 모두 특정 동작(이벤트)가 발생했을때 반응한다. 이벤트 드리븐이란 특정 이벤트가 발생하면 그에 따라 동작하는 방식을 이벤트 드리븐이라고한다.이는 브라우저, node.js, GUI프로글매 등에서 사용된다. 

<br/>


## 2\. 이벤트 드리븐의 구조

<br/>
  

이벤트 기반 프로그래밍에서는 이벤트가 발생하기 기다리는 **event loop** 가 핵심이다. 

이벤트 루프는 계속해서 큐에 쌓인 작업을 확인하고 실행 가능한 작업을 하나씩 꺼내 처리한다. 
<br/>
<br/>

  

* * *
<br/>

### 이벤트 루프?

- call stack : 함수가 실행될 때 쌓이는 공간
- Event Queue : 나중에 실행될 콜백 함수가 대기하는 공간
- Event Loop: 둘 사이를 연결해주는 중개자
  
<br/>
<br/>

#### 예시 흐름 :

1. 사용자가 클릭( 이벤트 발생 ) → 이벤트 등록된 콜백 함수가 큐(queue) 에 들어감.
2. 현재 실행중인 작업이 끝나면 이벤트 루프가 큐를 확인
3. 대기중인 콜백 실행

  

<p class="gray-text-200">! 이벤트 루프에 대한 더 자세한 정리는 브라우저 내 자바스크립트 실행 방식에 대해 추가 포스팅을 작성하겠다. </p>

## 3\. 이벤트 드리븐의 장단점
<br/>

- 장점
    - 1\. 반응형 인터페이스 구현에 적합
    - 2\. 비동기 작업 처리에 유리( 서버요청, 타이머 등)
    - 3\. CPU효율성 : 필요할떄만 작업 수행
- 단점
    - 1\. 이벤트 흐름 추측의 어려움 ( 콜백지옥, 예측 어려움)
    - 2\. 상태관리가 복잡해질 수 있음 ( 비동기 로직이 많을수록)
